Core Differentiator

Rule-Based Recurring Civic Issue Detection Engine

When a new complaint is filed, CivicSphere compares it against historical resolved and closed records using deterministic Java scoring—requiring category, location proximity, and description similarity before raising a candidate alert.

Candidates scoring 70/100 or higher are queued for administrator confirmation or rejection, protecting repair accountability.

Same Complaint Category30 pts
Location Match (Haversine ≤100m or Area/City/Landmark)40 pts
Description Keyword Similarity (Jaccard)20 pts
Prior Complaint Resolved / Closed10 pts
Recurrence Alert Threshold≥ 70 / 100 pts
